# TUI 输入与任务交互改进

本轮实现输入预测、插嘴与下一任务队列、内容操作、功能面板、模型快捷选择、任务中心与提醒、诊断和输入保护，并接通普通 TUI 对话中的文字＋参考图生图。

## 常用入口

| 操作 | 入口 |
|---|---|
| 搜索功能、设置和命令 | F1 或 `/commands`，支持中文搜索、最近使用 |
| 回复、选区、代码、附件操作 | Alt+A、右键或 `/actions` |
| 代码复制／保存 | 代码块标题行的「复制代码」「另存为」 |
| 模型收藏与最近使用 | Alt+M 或 `/model`；F2 收藏；`/model previous` 返回最近的另一模型 |
| 当前任务补充要求 | 运行中 Enter；显示等待纳入和实际纳入的轮次 |
| 当前任务结束后的下一条 | 运行中 Alt+Enter；与当前任务补充分开 |
| 查看、撤回／编辑、排序消息 | Alt+Q 或 `/queue`；撤回后可在草稿中修改，Alt+Enter 重新排队 |
| 停止并改方向 | 草稿非空且任务运行时，队列菜单中的「停止当前任务并发送草稿」 |
| 暂存／取回草稿 | 普通输入框 Ctrl+S；`/drafts` 取回，Delete 移除 |
| 普通输入撤销／重做 | Ctrl+Z／Ctrl+Y；批准、问题、编辑器保留各自原有按键 |
| 任务中心 | `/tasks`；Tab 筛选主任务、子代理、后台操作、终端命令；Enter 定位 |
| 诊断与短连接测试 | `/diagnose`，可复制脱敏诊断或打开来源设置 |
| 图片操作 | 双击图片文件行；弹窗内 S 另存为、C 复制图片、R 作为参考图加入草稿 |

原有命令继续可用。任务、代理、后台命令共用总览入口，保留各自权限、归属和停止规则。

## 灰字预测与提醒

输入框为空且当前任务正常结束后，后台使用当前模型生成一条简短建议。Tab 只把建议填入可编辑草稿，不会自动发送。输入自己的文字即可忽略，Esc 可关闭当前建议。命令和文件补全保留原有优先级；过期会话、请求或已有新草稿时丢弃预测。

`/suggest on|off` 开关预测；预测是独立模型短请求（最多约 80 个输出 token，最多等待 8 秒），供应商可能计费。预测只使用当前会话的少量文字片段，不主动发送图片、工具、记忆或连接数据。

`/notifications on|off` 开关提醒。任务结束、失败、等待批准或回答时请求提醒；窗口失焦时通过终端通知协议发出，实际展示受终端支持和设置影响。通知不启动额外模型请求。

模型收藏、最近模型、最近命令及开关保存在原 TUI 配置中。草稿暂存架仅在当前窗口有效，并按会话区分；队列归发起窗口所有，窗口退出后不会再启动后续任务。保存代码和图片使用新建文件方式，不覆盖已有文件。

## 文字＋参考图生图

先配置支持生图和图片编辑的服务，并启用对话配图。将参考图加入 TUI 草稿，输入修改要求正常发送。模型调用 `generate_image` 时，本轮实际选中的图片会经过已有参考图准备流程，随提示词一起传入生图接口。OpenAI 兼容服务使用 `/images/edits`；Gemini 原生服务使用已有多模态图片生成路径。

也可以预览已生成的图片，按 R 将它作为下一轮参考图，再输入修改要求。无需手动查找历史图片的磁盘路径。

参考图无效、不可用、超过接口数量限制或被上下文选择全部排除时，明确报告失败，不静默退回纯文生图。成功记录保留参考图信息，回复显示参考图传递回执。已有预算、工具批准、取消和每轮生图限制继续生效。

## 验证

验证覆盖：灰字预测只填草稿、过期结果和跨会话回执、输入撤销／草稿恢复、队列与插嘴分离及一次性调度、查询不可写、代码源文本与缩进、保存不覆盖、窄窗口和双宽字符布局、图片像素传递与参考图复用。

测试、构建和本机激活的实际结果记录在 `output/tui-convenience-20261030/`；模型链路测试使用本地合成服务，不代表已经验证每个第三方中转的生图兼容性。
