# TUI 图片弹窗

图片生成结果和创作历史中的“终端内预览”现在返回图片数据，由 TUI 在居中小窗口中渲染。原“系统查看器”功能保留为单独按钮，预览图片不再默认启动 Explorer。

- 自动选择终端支持的 Sixel / Kitty / iTerm2 图片协议；不支持时使用彩色半块字符。
- 按比例适应窗口，F 放大/还原，Esc、Enter、q、右上角关闭按钮或点击外部关闭。
- 保留底层表单与输入草稿；弹窗打开时键盘、粘贴和鼠标不会误操作底层页面。
- 后台单线程完成解码、缩放与编码；最多排队一项。关闭、重开和调整尺寸时丢弃过时结果。
- 关闭或改变尺寸时清除旧终端图像区域，避免残影；链接处理不会把图片协议数据当作文件路径或文本宽度。
- 支持 PNG / JPEG / GIF / WebP / BMP，最大 5 MiB、约 1600 万像素。GIF 显示首帧。原图可使用系统查看器。
- Host 返回的数据保持在现有 8 MiB WebSocket 帧限制以内；不需要为预览重新下载或生成图片。

依赖使用 ratatui-image 10.0.0，禁用 chafa 与不需要的图片格式，不引入额外的图片查看器 DLL。程序启动时在读取键盘事件前检测图片协议；检测等待上限为 400 ms，失败时降级为半块字符。

用户在开发过程中明确要求停止回归测试并自行测试；因此后续仅编译、打包与切换本机程序，不继续执行回归或图形界面验收。停止前一条测试仅接受半块字符，而同色上下像素会被渲染器编码为彩色空格，已修正该断言，未重新运行。

使用：重新启动 `expert`，进入 `/media`，打开创作历史中的图片，选择“终端内预览”。也可执行 `expert --preview-image 图片路径`。

## 对话附件双击预览

双击对话中的图片文件行（图标、文件名或大小）即可打开同一个终端内图片弹窗，适用于助手生成图片和用户已发送图片。输入框中的图片附件标签也使用此弹窗。Esc 关闭、F 放大/还原，输入草稿保持不变。

文件行命中使用渲染布局中的消息与附件 ID，不依赖文件名搜索；滚动、固定提问栏、侧栏、窄窗口与同名附件不会打开另一条图片。预览结果只在原会话中显示。Host 返回受 5 MiB 上限约束的图片数据，不创建临时文件或启动 Explorer。

新能力标记为 `terminal.attachment-image-preview.v1`。新版客户端发现旧 Host 时使用既有的空闲升级流程；有活动任务时保留旧 Host，等待任务结束再重新启动。无需重新生成图片。

本次验证：Rust 图片预览和对话定位共 13 项测试、Dart 附件共 8 项测试通过，修改文件静态分析无问题；独立 Host 使用本地合成的助手图片消息验证了预览数据回执，没有调用模型服务。客户端 Release 和 Dart CLI bundle 编译完成。本机安装记录见 `output/attachment-preview-deployment-20261029.json`。
